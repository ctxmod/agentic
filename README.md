# Agentic

Doctrine and workflow skills for agentic work, for ctxmod.

Profiles:

- `core` (default): verification and evidence, orchestration, and delegation.
- `workflows`: workflow skills — discovery, analysis, planning, implementation, validation, remediation, research, review, reporting, git, and cleanup. Extends `core`.
- `work`: planning and tracking work on the ctxmod work store. Extends `core`.
- `academic`: agentic academic work. Extends `core`.
- `teaching`: agentic teaching work. Extends `core`.

Select a profile by its selector, e.g. `github.com/ctxmod/agentic/context/profiles/workflows`.
