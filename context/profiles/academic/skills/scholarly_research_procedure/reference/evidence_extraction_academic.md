# Evidence Extraction

Structured extraction converts source material into reusable evidence units. Consistent extraction enables comparison, synthesis, and reliable citation across analyses.

## Extraction Components

Each evidence unit should capture:

| Component | Description |
|-----------|-------------|
| **Claim** | The specific finding or assertion |
| **Evidence** | Data, statistics, or reasoning supporting the claim |
| **Source location** | Page, section, or identifier for verification |
| **Context** | Conditions, limitations, or scope qualifiers |
| **Confidence** | Assessment of evidence strength |

## Extraction Depth

Match extraction depth to intended use:

**Quick summary** (screening and triage):
- One-sentence main contribution
- 2-3 key points
- Relevance assessment

**Standard extraction** (analysis and synthesis):
- Research question and methodology
- Key findings with supporting data
- Strengths and limitations
- Connection to current objectives

**Deep extraction** (critical engagement):
- Detailed methodology assessment
- All relevant findings with exact references
- Notable quotes with page numbers
- Critical analysis (internal validity, external validity, statistical adequacy)
- Relationship to other sources

## Exact Reference Tracking

Maintain exact source locations for all extracted evidence:

- **Page numbers** for print or paginated sources
- **Section identifiers** for structured documents
- **Timestamps** for time-based media
- **URLs with access dates** for web sources

Exact references enable verification and citation. Approximate references ("somewhere in Chapter 3") create citation debt that compounds during writing.

## Paraphrasing vs. Quoting

**Paraphrase** when the idea matters more than specific wording. Paraphrasing demonstrates understanding and integrates sources into your own analysis.

**Quote directly** when:
- Exact wording is analyzed or critiqued
- The phrasing is particularly precise or authoritative
- Defining a term from the source
- The original cannot be improved without losing meaning

Always include source location for direct quotes.

## Atomic Extraction

Extract one evidence unit per note or record. Atomic extraction enables:
- Reuse across multiple analyses
- Independent evaluation of each claim
- Flexible reorganization during synthesis
- Clear attribution for each piece of evidence

Compound extractions (multiple ideas in one note) create coupling that impedes later synthesis.
