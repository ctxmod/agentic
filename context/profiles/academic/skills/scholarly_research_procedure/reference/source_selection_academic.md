# Source Selection

Selecting appropriate sources determines research quality. Match source types to research objectives to maximize relevance and minimize noise.

## Source Type Matching

Different research objectives require different source types:

| Research Objective | Primary Sources | Secondary Sources |
|-------------------|-----------------|-------------------|
| State-of-the-art methods | Academic databases, preprint servers | Technical blogs, conference talks |
| Implementation guidance | Official documentation, repositories | Community forums, tutorials |
| Best practices | Industry reports, standards bodies | Practitioner discussions |
| Historical context | Academic databases, archives | Review articles, textbooks |
| Community consensus | Discussion forums, social platforms | Blog posts, survey results |

## Source Tiers

Organize sources by reliability for evidence hierarchies:

**Tier 1** (highest reliability):
- Peer-reviewed journals and conference proceedings
- Official standards and specifications
- Primary data sources and registries

**Tier 2** (moderate reliability):
- Preprint servers (not yet peer-reviewed)
- Official documentation and technical reports
- Established reference works

**Tier 3** (supporting context):
- Blog posts and tutorials from recognized practitioners
- Community discussions and forums
- News articles and industry reports

Use Tier 1 sources for claims requiring strong evidence. Tier 2 and 3 sources provide context, practical guidance, and emerging perspectives.

## Coverage Strategy

Systematic coverage reduces the risk of missing relevant sources:

1. **Start broad**: Use general search tools to map the landscape
2. **Follow citations**: Trace references from high-quality sources to find related work
3. **Check recency**: Verify whether newer work supersedes earlier findings
4. **Cross-domain**: Check adjacent fields for applicable methods or findings
5. **Validate saturation**: Stop when new sources repeat known information

## Anti-Patterns

| Anti-Pattern | Consequence |
|--------------|-------------|
| Single-source reliance | Misses contradictory evidence or alternative approaches |
| Recency bias | Ignores foundational work that remains relevant |
| Authority bias | Accepts claims based on source prestige rather than evidence |
| Convenience sampling | Uses only easily accessible sources, missing important restricted ones |
