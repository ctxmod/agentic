# scholarly_research

Research foundational concepts and theoretical foundations from academic sources.

Usage:

```text
/scholarly_research [topic]
```

| Argument | Required | Description |
| --- | --- | --- |
| `topic` | yes | Topic or question to research from academic sources |

Work-item context: optional.

Launch the `scholarly_research_phase` agent with the command arguments in a brief that grants the `scholarly_research_phase` skill:

```text
<ctxmod_activate skill="agentic_academic_scholarly_research_phase" />
<command arguments>
```
