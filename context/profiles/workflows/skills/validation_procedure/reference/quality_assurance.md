# Quality Assurance

Systematic checklists for validating research sources and outputs

Quality assurance applies structured checklists at decision points: before relying on a source, before citing a finding, and before finalizing a document. Checklists catch systematic errors that ad-hoc review misses.

## Source Reliance Checklist

Before investing significant time in a source, verify:

- [ ] Publication venue: recognized journal, conference, or publisher
- [ ] Author credentials: domain expertise, institutional affiliation, track record
- [ ] Methodological rigor: appropriate design, adequate sample, valid measures
- [ ] Finding quality: results support conclusions, limitations acknowledged
- [ ] Research integration: findings align with or productively challenge existing knowledge
- [ ] Currency: recent enough for the field, not superseded by newer work
- [ ] Conflicts of interest: funding sources and affiliations declared

Sources that fail two or more items warrant replacement with stronger alternatives. Apply this checklist early to avoid sunk-cost attachment to weak sources discovered late in the research process.

## Citation Readiness Checklist

Before citing a source in writing, confirm:

- [ ] Direct quotes verified against original text (page number recorded)
- [ ] Paraphrased claims accurately represent source meaning and scope
- [ ] Interpretation is fair: not cherry-picked, not decontextualized
- [ ] Statistical claims include effect sizes and confidence intervals where available
- [ ] Finding is not contradicted by stronger evidence in the collection
- [ ] Source is properly entered in reference management system with full metadata

Citing a finding that fails any item risks propagating inaccuracies into the final document. Run this checklist per citation, not per document.

## Standalone Document Checklist

Before finalizing a research document, verify:

- [ ] All claims attributed with numbered citations and full source URLs
- [ ] No references to internal draft files or working documents
- [ ] Cross-references use relative paths to other finalized documents only
- [ ] First-hand information includes attribution (name, context, date)
- [ ] Document is self-contained: a reader with no prior context can follow it
- [ ] Technical terms defined on first use
- [ ] Confidence levels stated for uncertain findings
- [ ] Contradictory evidence acknowledged where it exists
- [ ] Structure supports random access: sections comprehensible independently

## Periodic Audit

Scheduled review prevents gradual quality erosion across an active research corpus. Without periodic re-assessment, confidence levels drift as new evidence emerges and previously strong sources become outdated.

**Monthly**:

- Verify citation accuracy for recently cited sources
- Check for newly published evidence that contradicts current findings
- Update confidence levels for findings where the evidence base has shifted

**Quarterly**:

- Run a comprehensive validation audit across the active research corpus
- Archive sources no longer relevant to current research questions
- Refresh quality assessments for key sources using the source reliance checklist

## Anti-Patterns

| Anti-Pattern | Consequence | Alternative |
|-------------|-------------|-------------|
| Validating only at submission | Errors compound through drafts unchecked | Validate at each decision point: source selection, citation, and finalization |
| Skipping the source reliance checklist for familiar authors | Authority bias overrides methodological assessment | Apply the checklist uniformly regardless of author reputation |
| Citing secondary summaries instead of primary sources | Misinterpretation propagates through citation chains | Trace claims to the original study and cite it directly |
| Omitting confidence levels for uncertain findings | Readers cannot distinguish strong evidence from speculation | State confidence explicitly and document supporting evidence |
