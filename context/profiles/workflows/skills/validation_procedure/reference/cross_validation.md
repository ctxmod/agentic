# Cross-Validation

Cross-validation confirms findings by checking them against independent evidence. Single-source findings carry inherent risk; multi-source validation builds confidence.

## Triangulation Strategies

### Data Triangulation

Validate findings using multiple data sources:

1. Compare findings across independent datasets
2. Check if patterns hold in different contexts or populations
3. Identify consistent results versus context-dependent ones

Consistent findings across independent data sources significantly increase confidence. Inconsistent findings signal boundary conditions or measurement issues.

### Method Triangulation

Apply different methods to the same question:

1. Compare quantitative and qualitative findings
2. Apply alternative analytical approaches
3. Check if different methods produce convergent results

Method convergence reduces the risk that findings are artifacts of a particular methodology.

### Source Triangulation

Verify claims against multiple independent authorities:

1. Check academic sources against practitioner reports
2. Compare official documentation against community experience
3. Verify vendor claims against independent evaluations

Independent sources reaching the same conclusion without coordination provide stronger evidence than multiple citations from the same research group.

## Replication Assessment

Document whether findings have been independently replicated:

| Status | Meaning | Confidence Impact |
|--------|---------|-------------------|
| **Replicated** | Independent researchers confirmed findings | Strong evidence |
| **Partially replicated** | Some aspects confirmed, others untested | Supported but incomplete |
| **Not replicated** | No independent confirmation exists | Single-source evidence |
| **Failed replication** | Independent attempts produced different results | Requires investigation |

## When Findings Conflict

Cross-validation often reveals contradictions. When sources disagree:

1. Verify the contradiction is genuine (check scope, definitions, methods)
2. Assess relative credibility of conflicting sources
3. Document both positions and the basis for any preference
4. Note what further evidence would resolve the disagreement
