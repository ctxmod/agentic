# Critical Analysis

Assess individual sources through structured analytical frameworks

Critical analysis evaluates individual sources across three dimensions: methodology, theoretical framework, and contribution. Structured assessment prevents impressionistic judgments and produces reusable evaluations that feed into cross-source synthesis.

## Methodological Assessment

Evaluate whether the research design supports the claims made. Each element of methodology contributes independently to overall validity.

| Dimension | Key Questions |
|-----------|--------------|
| **Research design** | Does the design match the stated questions? Are threats to internal validity addressed? |
| **Sample/data** | Is the sample size adequate for the analysis? Are selection criteria justified and representative? |
| **Measures/instruments** | Are instruments validated for this context? Do operationalizations capture intended constructs? |
| **Analysis approach** | Are analytical methods appropriate for the data structure? Are assumptions verified and reported? |

Assess each dimension independently before forming an overall methodological judgment. A strong design with weak measures produces different limitations than weak design with strong measures.

Rate each dimension on a three-level scale:

- **Strong**: Appropriate for the research question, well-documented, limitations acknowledged
- **Adequate**: Reasonable choices with minor gaps or undocumented assumptions
- **Weak**: Misaligned with the research question, undocumented, or methodologically flawed

The overall methodological rating reflects the weakest dimension that affects the source's central claims. Peripheral weaknesses (e.g., limited demographics reporting when demographics are not central to the argument) reduce overall confidence less than weaknesses in the core analytical chain.

## Theoretical Framework Analysis

Examine how the source positions itself within existing knowledge:

- **Framework clarity**: Is the theoretical basis explicitly stated, implicitly applied, or absent? Implicit frameworks limit reproducibility and make assumptions harder to evaluate.
- **Grounding**: How does the framework connect to established theory and prior empirical work? Trace the intellectual lineage.
- **Novelty**: Does the work extend an existing framework, combine multiple frameworks, or challenge established ones? Each type carries different evidentiary burdens.
- **Coherence**: Does the methodology align with the theoretical framework? Misalignment between framework assumptions and methodological choices weakens both.

When a source lacks an explicit framework, reconstruct the implicit one from its assumptions, variable selection, and interpretive choices. Document this reconstruction as part of the analysis.

## Contribution Assessment

Assess what the source adds relative to existing knowledge. Contribution type determines assessment criteria.

| Contribution Type | Assessment Criteria |
|-------------------|-------------------|
| **New method** | Does it solve a methodological limitation? Is it validated against existing approaches? |
| **New application** | Does the new context reveal different dynamics? Are adaptations justified? |
| **New finding** | Does it replicate or contradict prior results? Is the evidence proportional to the claim? |
| **New synthesis** | Does it generate insight beyond individual sources? Are integration choices transparent? |

Evaluate four aspects for each contribution:

1. **Gap addressed**: What specific gap does this work fill, and is that gap genuine?
2. **Novelty**: What is new relative to the closest existing work?
3. **Rigor**: Does methodological quality support the contribution claims?
4. **Significance**: What does this enable for subsequent work or practice?

## Dialogic Analysis

Position the source within ongoing scholarly conversation using the "They Say / I Say" framework:

1. **What does the source argue?** Identify the central thesis and supporting claims.
2. **What evidence supports it?** Map evidence to each claim, noting strength and type.
3. **How does this relate to competing claims?** Locate the argument relative to agreement, extension, and opposition in the field.
4. **What does this enable?** Identify research directions, methodological possibilities, or practical applications this work opens.

This framework moves analysis beyond summary toward analytical positioning. For literature reviews, dialogic analysis produces paragraphs that situate sources within debates rather than listing findings sequentially.

Dialogic analysis also surfaces implicit disagreements. Two sources may report compatible findings yet operate from incompatible theoretical assumptions. Identifying these tensions early prevents superficial synthesis that papers over genuine conceptual conflict.

## Anti-Patterns

| Anti-Pattern | Consequence | Alternative |
|-------------|-------------|-------------|
| Summary without evaluation | Descriptive review lacking analytical depth | Assess alongside summarizing; state what works and what does not |
| Uniform praise or criticism | Unbalanced analysis that misrepresents source quality | Evaluate each dimension independently; most sources have both strengths and weaknesses |
| Evaluating against wrong standard | Penalizing exploratory work for lacking confirmatory rigor, or vice versa | Match evaluation criteria to the source's stated aims and contribution type |
| Isolated analysis | Evaluation disconnected from the broader field | Use dialogic analysis to position the source relative to competing and supporting work |

## Assessment Sequence

Apply the four sections in order. Methodological assessment establishes what the source can credibly claim. Theoretical framework analysis reveals the interpretive lens shaping those claims. Contribution assessment determines what the source adds given its methodological limits and theoretical positioning. Dialogic analysis then places the evaluated source within the broader conversation.

This sequence prevents a common failure mode: evaluating contribution before understanding methodology, which leads to overvaluing weak evidence that fills an appealing gap.
