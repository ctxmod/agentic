# Pattern Aggregation

Pattern aggregation transforms individual evidence units into synthesized understanding. The goal is identifying convergence, divergence, and gaps across sources rather than summarizing sources sequentially.

## Synthesis Approaches

### Thematic Synthesis

Group evidence by theme rather than by source:

1. **Extract atomic evidence** from each source
2. **Code evidence units** by topic, concept, or claim
3. **Cluster codes** into themes
4. **Identify patterns** within and across themes
5. **Note gaps** where evidence is absent or thin

### Comparative Analysis

Compare sources across consistent dimensions:

| Dimension | Source A | Source B | Source C | Synthesis |
|-----------|---------|---------|---------|-----------|
| Methodology | | | | |
| Key findings | | | | |
| Limitations | | | | |
| Implications | | | | |

Comparative matrices reveal complementary strengths, contradictions, and collective gaps.

### Chronological Tracing

Track how understanding evolved:

1. Identify foundational claims
2. Trace how subsequent work confirmed, refined, or contradicted them
3. Note paradigm shifts and their evidence bases
4. Assess current consensus

## Synthesis Quality

Effective synthesis demonstrates analytical engagement:

**Sequential listing** (avoid):
> "Smith found X. Jones found Y. Johnson found Z."

**Synthesized relationships** (target):
> "While Smith emphasizes X, Jones focuses on Y. Johnson demonstrates both factors interact to produce Z, suggesting a mechanism that reconciles the earlier partial accounts."

## Consensus and Disagreement

Classify aggregated findings:

| Classification | Description | Action |
|---------------|-------------|--------|
| **Consensus** | Multiple independent sources converge | Report as established finding with sources |
| **Emerging agreement** | Limited but consistent evidence | Report with appropriate hedging |
| **Active disagreement** | Sources present conflicting evidence | Document both positions and possible explanations |
| **Silence** | No sources address the question | Document as gap requiring investigation |

## Gap Identification

Gaps emerge from synthesis, not from individual sources:

- **Coverage gaps**: Topics no source addresses
- **Methodological gaps**: Approaches no source has tried
- **Population gaps**: Contexts no source has studied
- **Temporal gaps**: Time periods with no data

Document gaps with the same rigor as findings. Gaps inform future directions and qualify the strength of existing conclusions.
