# Contradiction Resolution Procedure

Resolve conflicting findings by treating contradictions as learning opportunities. This procedure transforms apparent conflicts into boundary conditions that explain when each finding applies.

## Prerequisites

- Two or more conflicting findings identified with source attribution
- Access to original sources for contextual analysis
- Clear understanding of the claims in conflict

## Steps

### 1. Document the Contradiction

State each conflicting position explicitly with its source:

```
Finding A: "Technique X improves performance by 30%" [Source 1]
Finding B: "Technique X shows no significant improvement" [Source 2]
```

Record the specific metrics, conclusions, or recommendations that conflict.

### 2. Analyze Contextual Differences

Examine each source for contextual factors that may explain the divergence:

| Factor | Questions to Ask |
|--------|------------------|
| Recency | When was each study conducted? Have conditions changed? |
| Methodology | How did each source measure outcomes? |
| Population | Who or what was studied? Sample size differences? |
| Setting | What environment or conditions applied? |
| Definitions | Do sources define key terms identically? |

### 3. Map the Dialectic

Structure the conflict as thesis and antithesis:

- **Thesis**: State the first position and its supporting conditions
- **Antithesis**: State the opposing position and its conditions
- **Synthesis**: Identify a higher-order framework that accommodates both

Example synthesis: "Technique X improves performance in memory-constrained environments but shows no benefit when memory is abundant."

### 4. Develop Boundary Conditions

Specify when each finding applies. Transform "A vs B" into "A when X, B when Y":

- List conditions favoring Finding A
- List conditions favoring Finding B
- Identify overlapping or ambiguous zones

### 5. Document Resolution Rationale

Record the reasoning behind your synthesis. Include:

- Which contextual factors proved decisive
- Why you weighted certain factors over others
- Any remaining uncertainty or gaps

## Decision Points

**No contextual differences found**: Consider that one source may contain errors. Assess methodology rigor and sample sizes. Prefer the source with stronger methodology.

**Partial overlap in conditions**: Acknowledge the ambiguous zone explicitly. State what additional research would resolve it.

**Irreconcilable conflict**: Report both findings with context rather than forcing synthesis. Note: "Current evidence does not support definitive resolution."

## Success Criteria

- All conflicting findings documented with sources
- Contextual analysis completed for each source
- Synthesis articulated as boundary conditions
- Resolution rationale recorded transparently
- No findings "averaged" or silently ignored

## Common Issues

**Premature synthesis**: Rushing to resolution before fully analyzing context. Complete Step 2 thoroughly before attempting synthesis.

**False equivalence**: Treating weak and strong sources as equal. Weight findings by methodology quality and source authority.

**Averaging conflicts**: Stating "the truth is somewhere in between" without boundary conditions. This obscures rather than resolves the conflict.

**Ignoring inconvenient findings**: Excluding findings that complicate the narrative. Include all findings; let boundary conditions explain variance.
