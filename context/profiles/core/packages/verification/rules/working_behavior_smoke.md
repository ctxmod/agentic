# Working-Behavior Smoke Before Live Claims

A "live/deployed" claim requires a working-behavior smoke of the primary user journey against the deployed artifact — authenticated call plus rendered UI theme tokens — never build success plus endpoint 200s; a genuine gate also records execution evidence such as its duration.

Test: the claim cites the executed primary journey, checked by computed style in a real or headless browser rather than by structure, and a zero-second pass counts as a skip.

The full rule, the incidents, and the smoke scope: [working_behavior_smoke_detail.md](../reference/working_behavior_smoke_detail.md).
